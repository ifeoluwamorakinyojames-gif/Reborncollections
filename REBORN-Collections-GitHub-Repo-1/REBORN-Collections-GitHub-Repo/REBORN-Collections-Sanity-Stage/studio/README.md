# REBORN Sanity Studio

This is the new content/admin backend for REBORN Collections.

Project ID: `unv7o4vs`
Dataset: `production`

## Run locally

```bash
npm install
npm run dev
```

Then sign in with the Sanity account that owns the project.

Create one `Site Settings` document, then add `Product` documents.

## Deploy Studio

```bash
npm run deploy
```

Sanity will ask you to choose a Studio hostname.
